Website Evaluations

Apple

The Apple website offers a sleek platform where users can browse and purchase Apple products. It has detailed descriptions of each product. It's polished and user-friendly and the minimal design allows user to easily naviagte through the website and what it offers.

  • Contrast: Good contrast between the background and the text. The white background allows the other elements on the page to stand out. Elements are also easily distinguished from each other
  • Repetition: Good use of font size to distinguish different sections, meaning that all headings have the same color and size, all product names have the same style, etc. which helps with navigations
  • Alignment: Everything is well-aligned and intentionally placed. The page is well-balanced on both sides and no side seems to carry more weight
  • Proximity: The use of spacing allows to users to group elements together, enhancing readbility


Berkshire Hathaway

The website provides information regarding other businesses they work with and yearly financial reports. I doesn't contain any images and relies heavily on text to relay its message.

  • Contrast: The color contrast is good with the blue font on white background, but the individual elements are not distinguishable from each other
  • Repetition: It's is too repetitive in that everything looks and feels the same, making the website rather hard to navigate at first glance
  • Alignment: No interesting structure. It's all just given in a list of links. The organization changes very frequently with each new link you click, which does allow for uniformity between the different pages
  • Proximity: The content is sometimes too spaced out to fill up the page and sometimes too close together when there is too much text
